# User Guide Regression Test Plan

**Purpose:** Programmatically validate every feature described in `USER_GUIDE.md` as an automated regression suite. Each section maps to one or more test files that exercise the feature end-to-end against real ICD documents.

**Goal:** A single `pytest` command that validates the entire user-facing workflow — from upload through editing, comparison, search, and export — producing a pass/fail report suitable for CI/CD gating.

---

## Test Infrastructure

### Existing Test Structure

```
tests/
├── conftest.py                  # .test-env loading, ICD auto-indexing, WeasyPrint markers
├── unit/                        # Fast, no Docker required
│   ├── test_briefing.py         # Briefing consolidation module (24 tests)
│   ├── test_element_classification.py  # Element type detection (17 tests)
│   ├── test_version_diff.py     # Version diff pipeline (32 tests)
│   ├── test_pipeline.py         # PDF extraction pipeline
│   ├── test_models.py           # Pydantic models
│   └── ...
├── integration/                 # Requires Docker backend running
│   ├── test_compare_pipeline.py # Briefing API + section quality (19 tests)
│   ├── test_table_panel_crud.py # Table add/delete row
│   └── alpha_*.py / audit_*.py  # Development inspection scripts
└── docker/                      # Runs inside Docker container
    ├── test_export_pdf.py       # WeasyPrint-dependent rendering
    └── ...
```

### Running Tests

```bash
# Unit tests (fast, no Docker needed)
python -m pytest tests/unit/ -v

# Integration tests (Docker must be running)
python -m pytest tests/integration/ -v

# Full suite
python -m pytest tests/ -v --ignore=tests/integration/alpha_*.py
```

### Test Conventions

- All tests use documents from `icds/digital/` (checked into repo via git-lfs)
- Document IR files auto-generated by `conftest.py` at session start
- Tests that need the API running are marked or placed in `integration/`
- Tests use `pytest.mark.skipif` when required documents don't exist

## PDF Output Verification (Cross-cutting)

**Question:** Can we verify the output PDF content and format for specifically what was updated?  
**Answer:** Yes. The test suite opens exported PDFs with PyMuPDF, extracts text per page, and compares against expected values.

**Question:** Are changes singular or cumulative? Can we test both?  
**Answer:** Both. Tests should cover:
- **Singular:** One edit → export → verify that single change appears correctly
- **Cumulative:** Multiple edits in sequence → single export → verify ALL changes present and no interference

#### Methodology

```python
import fitz

def verify_export(client, page_num, expected_text_fragment):
    """Export the current document and verify text on a specific page."""
    res = client.get("/document/export-download?filename=verify.pdf")
    doc = fitz.open(stream=res.content, filetype="pdf")
    page_text = doc[page_num - 1].get_text("text")
    doc.close()
    assert expected_text_fragment in page_text

def verify_position(client, page_num, text_fragment, expected_y, tolerance=15):
    """Verify that specific text appears near an expected Y coordinate."""
    res = client.get("/document/export-download?filename=verify.pdf")
    doc = fitz.open(stream=res.content, filetype="pdf")
    page = doc[page_num - 1]
    blocks = page.get_text("dict")["blocks"]
    for block in blocks:
        if block.get("type") != 0:
            continue
        for line in block.get("lines", []):
            for span in line.get("spans", []):
                if text_fragment in span.get("text", ""):
                    actual_y = span["bbox"][1]
                    assert abs(actual_y - expected_y) < tolerance, (
                        f"Text '{text_fragment}' at y={actual_y}, expected ~{expected_y}"
                    )
                    return
    assert False, f"Text '{text_fragment}' not found on page {page_num}"

def verify_unedited_pages_identical(client, source_path, edited_pages):
    """Verify all non-edited pages match the source exactly."""
    res = client.get("/document/export-download?filename=verify.pdf")
    export_doc = fitz.open(stream=res.content, filetype="pdf")
    source_doc = fitz.open(str(source_path))
    for i in range(len(source_doc)):
        if (i + 1) in edited_pages:
            continue
        assert export_doc[i].get_text("text") == source_doc[i].get_text("text"), (
            f"Page {i+1} changed unexpectedly (should be untouched)"
        )
    export_doc.close()
    source_doc.close()
```

## Success Criteria

The regression suite passes when:

1. **All `test_ug_*.py` tests pass** (zero failures)
2. **No test requires manual intervention** (fully automated)
3. **Each user guide section has ≥1 corresponding test file**
4. **Known edge cases from alpha tuning are covered** (HSI overlap, IDSS boilerplate, TOC misclass)
5. **Total runtime < 5 minutes** (parallel where possible)
